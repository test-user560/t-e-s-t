# Github 가이드

> 이 안내는 GitHub에 이미 로그인한 상태에서 시작합니다.   

지금부터 GitHub에서 새 레포지토리를 만들고,      
그 안에 파일을 올리고 관리하는 방법을 하나씩 따라 해 보겠습니다.


## 1. 새 레포지토리 만들기

GitHub 화면 오른쪽 위에 있는 `+` 버튼을 누릅니다.



<img width="800"  src="https://github.com/user-attachments/assets/d4521ffa-9f50-400d-b2e8-4caf1838be30" alt="레포지토리 생성 버튼 클릭" />
 

## 2. 레포지토리 정보 입력하기

`Repository name` 칸에 만들고 싶은 레포지토리 이름을 입력합니다.    
처음 연습할 때는 `my-first-repository`처럼 영어와 하이픈을 사용하면 좋습니다.        
입력이 끝나면 아래쪽의 `Create repository` 버튼을 누릅니다.   

<img width="800" alt="스크린샷 2026-06-12 08 49 28" src="https://github.com/user-attachments/assets/33f9398e-f81b-4c91-9edc-dcfa8ada1665" alt="New repository 버튼 클릭"  />

## 3. 만들어진 레포지토리 확인하기

레포지토리가 만들어지면 파일을 관리할 수 있는 화면이 열립니다.  
이곳에서 파일을 올리거나, 새 파일을 만들거나, 기존 파일을 수정할 수 있습니다.

<img width="800" alt="스크린샷 2026-06-12 08 50 01" src="https://github.com/user-attachments/assets/ca136c96-92a7-4e79-b77e-6f1b10914eba" alt="레포지토리 생성 설정" />

## 4. 레포지토리에 파일 올리기

레포지토리 화면에서 `Add file` 버튼을 누릅니다.  
컴퓨터에 있는 파일을 올리려면 `Upload files`를 선택합니다.

파일을 끌어다 놓거나, `choose your files`를 눌러 파일을 선택합니다.  
파일을 모두 선택했다면 아래쪽의 `Commit changes` 버튼을 눌러 저장합니다.

<img width="800" alt="스크린샷 2026-06-12 08 50 58" src="https://github.com/user-attachments/assets/181c524c-3c72-43ad-8f08-c191346e468d" alt="레포지토리 화면 설명" />

## 5. 파일 상세보기 화면에서 파일 수정하기

수정하고 싶은 파일 이름을 누릅니다.  
파일 내용이 보이는 상세보기 화면으로 이동합니다.

오른쪽 위에 있는 연필 모양 버튼을 누르면 파일을 수정할 수 있습니다.  
수정을 마친 뒤에는 화면 상단 초록색 버튼에 `Commit changes` 버튼을 눌러 변경 내용을 저장합니다.

<img width="800" alt="스크린샷 2026-06-12 08 51 03" src="https://github.com/user-attachments/assets/080257f5-1b2c-4572-846c-8e93a581edb3" alt="레포지토리 파일 수정 방법 설명" />

## 6. 파일 저장 및 기록하기

`Commit changes...` 버튼을 누르면 확인 창이 열립니다.  
이 창에서는 수정한 내용을 저장하기 전에 한 번 더 확인할 수 있습니다.

`Commit message` 칸에는 변경 사항의 제목이 들어갑니다.  
처음에는 GitHub가 자동으로 넣어 준 문장을 그대로 두어도 괜찮습니다.

<img width="1150" height="616" alt="스크린샷 2026-06-12 09 32 18" src="https://github.com/user-attachments/assets/ec80f5ef-ea3c-4770-a071-9dc3a0003b81" />

## 7. 수정한 내용 저장하기

확인 창 아래쪽에 있는 `Commit changes` 버튼을 누릅니다.  
이 버튼을 누르면 수정한 내용이 레포지토리에 저장됩니다.

저장이 끝나면 파일 상세보기 화면으로 돌아가며, 바뀐 내용을 확인할 수 있습니다.
